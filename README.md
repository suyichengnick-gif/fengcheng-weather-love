# 给你的每日天气情书 ♡

一个为江西省丰城市设计的中文天气恋爱小网站。包含实时天气、逐小时预报、降雨时段提示、按天气生成的穿搭建议、30 道午餐盲盒、每日情话和今日小任务。

## 本地运行

需要 Node.js 18.17 或更新版本。

```bash
npm install
npm run dev
```

浏览器打开 http://localhost:3000 。

## 天气数据

当前使用 Open-Meteo Forecast API，位置使用丰城市近似坐标（28.159, 115.786），时区设为 `Asia/Shanghai`。个人项目无需 API key。正式发布前请核对坐标、API 当前条款与数据可用性。天气预报具有不确定性，页面会将降雨概率达到 40% 或小时降水量达到 0.2 mm 的时段提示为潜在降雨时段，并非降雨保证。

## 部署

1. 将项目上传到自己的 GitHub 仓库。
2. 在 Vercel 导入该仓库。
3. Framework Preset 选择 Next.js，直接部署即可。
4. 部署完成后可以将网址发给女朋友，也可以在手机浏览器中添加到主屏幕。

## 注意事项

- 午餐和情话数据为本地数据，不依赖第三方服务。
- 收藏状态、当天午餐选择和今日小任务会按中国日期保存在当前浏览器；清除浏览器数据后会重置，也不会同步到其他设备。
- 当前天气刷新失败时会显示错误提示；页面刷新后不会把过期天气伪装成实时数据。
- 天气日期与小时数据以 Open-Meteo 的 `Asia/Shanghai` 时区响应为准；接口在午夜短暂跨日时，页面会跟随响应中可用的丰城预报日期，避免把一天的预报标成另一天。
